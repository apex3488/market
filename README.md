# BAYHAN MARKET

Интернет-магазин электроники и бытовой техники. «Технологии для жизни. Выбор без компромиссов.»

Текущий этап — **веб-магазин**: сайт + API + база данных + админ-панель. Telegram Mini App, мобильное приложение и онлайн-оплата (YooKassa / Stripe) — следующие этапы; схема БД уже содержит таблицы `payments` и `payment_events` под них.

## Структура

```
apps/api        REST API /api/v1 (Hono + Drizzle ORM + Zod), Neon PostgreSQL
apps/web        Next.js 16 (App Router), сайт и админка /admin
packages/shared общие типы, Zod-схемы, переводы RU/EN, API-клиент
```

Браузер не подключается к базе: сайт обращается к API через прокси Next.js (`/api/v1/*` → `API_INTERNAL_URL`), поэтому cookie сессии остаётся на домене сайта (httpOnly, SameSite=Lax).

## Запуск локально

Нужен Node.js 20+.

```bash
npm install
cp .env.example .env          # по умолчанию используется встроенная PGlite-база, Postgres не нужен
npm run db:seed               # миграции + демо-каталог (можно запускать повторно)
ADMIN_EMAIL=you@example.com ADMIN_PASSWORD=very-long-password npm run admin:create
npm run dev:api               # http://localhost:4000
npm run dev:web               # http://localhost:3000
```

Админ-панель: войдите под администратором и откройте `/admin`.
Демо-промокод: `DEMO5` (−5 % от 1 000 000 сум).

> Встроенная PGlite-база открывается только одним процессом: перед `db:seed` / `admin:create` остановите `dev:api`.

## Переменные окружения

| Переменная | Где | Назначение |
|---|---|---|
| `DATABASE_URL` | API | строка подключения Neon (`postgres://…?sslmode=require`) или `pglite:./.data/db` локально |
| `AUTH_SECRET` | API | обязательна в production (длинная случайная строка) |
| `WEB_URL` | API | адрес сайта (CORS, ссылки в письмах) |
| `CORS_ORIGINS` | API | дополнительные разрешённые origin через запятую |
| `STORE_CURRENCY` | API | валюта магазина, по умолчанию `UZS` |
| `DELIVERY_COURIER_FEE` | API | стоимость курьерской доставки в 1/100 валюты (`3000000` = 30 000 сум) |
| `RESEND_API_KEY`, `MAIL_FROM` | API | письма для восстановления пароля (без ключа ссылка пишется в консоль в dev) |
| `API_INTERNAL_URL` | Web | адрес API, доступный серверу Next.js |
| `SITE_URL` | Web | публичный адрес сайта (метаданные / OpenGraph) |

Секреты не попадают в браузер: у сайта нет `NEXT_PUBLIC_*` переменных.

## Neon

1. Создайте проект на [neon.tech](https://neon.tech), скопируйте connection string (pooled или direct, с `sslmode=require`).
2. Пропишите его в `DATABASE_URL`.
3. `npm run db:migrate` — применит SQL-миграции из `apps/api/drizzle`.
4. `npm run db:seed` — демо-каталог (опционально), затем `npm run admin:create`.

Изменили `apps/api/src/db/schema.ts` → `npm run db:generate`, затем `npm run db:migrate`.

## Production

```bash
npm run build                 # API (tsup → apps/api/dist) + сайт (next build)
npm -w @bayhan/api run start  # API, порт PORT (4000)
npm -w @bayhan/web run start  # сайт, порт 3000
```

### Vercel (текущий деплой)

Проект `bayhan-market` на Vercel собирается из `apps/web`; API встроен в Next.js (`app/api/v1/[...path]`), отдельный сервер не нужен.

- База: Neon, подключена через интеграцию Vercel — `DATABASE_URL` выставляется автоматически.
- `AUTH_SECRET` — обязателен; `SEED_DEMO=true` — при сборке добавляет недостающие демо-товары.
- Скрипт `vercel-build` сначала применяет миграции к Neon, затем собирает сайт. Каждый пуш в `main` деплоится автоматически.
- Администратор для продакшена: `vercel env pull .env.production.local`, затем `DATABASE_URL=… ADMIN_EMAIL=… ADMIN_PASSWORD=… npm run admin:create`.

Отдельный API-сервер (Render, Railway, VPS) тоже поддерживается: задайте сайту `API_INTERNAL_URL`.

## Что реализовано

- Каталог: 10 категорий, фильтры по цене / бренду / наличию / характеристикам категории, сортировка, пагинация, мгновенный поиск с подсказками.
- Страница товара: галерея, выбор конфигурации, остатки, характеристики, отзывы, похожие товары, JSON-LD для SEO.
- Корзина на сервере (гостевая по токену, переносится в аккаунт при входе), избранное, сравнение до 4 моделей.
- Оформление заказа: сервер сам считает цены, скидку и доставку, атомарно резервирует остатки, сохраняет снимок товаров; повторный запрос с тем же `Idempotency-Key` не создаёт дубль.
- Аккаунт: регистрация по email или телефону, вход, восстановление пароля, история и статусы заказов, отмена.
- Админ-панель: обзор, заказы (поиск, смена статусов по допустимым переходам), товары (варианты, цены, остатки, изображения, характеристики), категории, бренды, промокоды, клиенты и роли. Важные действия пишутся в `audit_logs`.
- Безопасность: пароли — scrypt; сессии — случайные токены, в БД хранится только SHA-256; CSRF-защита cookie-запросов; rate limit на вход / регистрацию / заказы; проверка прав администратора на сервере; валидация всех входных данных Zod.
- RU / EN во всём интерфейсе, язык сохраняется.

## Ограничения текущего этапа

- Онлайн-оплаты нет — доступна только «Оплата при получении».
- Rate limit хранится в памяти процесса (для нескольких инстансов нужен Redis).
- Изображения товаров задаются URL-ами (загрузка файлов потребует S3/R2-хранилища).
- Демо-каталог, цены и остатки носят ознакомительный характер. Фото — Unsplash.
